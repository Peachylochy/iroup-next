# Legacy Asset Library

ที่มา: `Peachylochy_iroup-portal/Team IROUP/assets`  
ปลายทาง: `public/legacy-assets/`  
สถานะ: เก็บไว้เพื่อใช้กับ iROUP Next ตามความเหมาะสม ยังไม่มีหน้าใหม่ใดอ้างอิง assets ชุดนี้โดยอัตโนมัติ

## เนื้อหา

- `IROUP_LOGO.webp`, `iroup-logo.png`, `Globy_IROUP.png`: ตราสัญลักษณ์และภาพหลักของแบรนด์
- `MOU-hero-earth-*.webp`, `landing-hero-earth-*.webp`: ภาพโลก/ความร่วมมือ
- `events-hero-*.webp`, `news-hero-*.webp`, `knowledge-hero-*.webp`, `scholarship-hero-*.webp`: hero ของแต่ละโมดูล
- `app-icon-*.png` และ `app-icon-*.webp`: app/PWA icons
- `sdg/`: ไฟล์ SDG icon/thumbnail ไทย

## กติกาการใช้งาน

1. ใช้ asset เดิมได้เมื่อทำให้หน้าจอใหม่รักษาบุคลิกของ iROUP เดิมได้ดีขึ้น
2. ห้ามทำสำเนา asset เพิ่มในโฟลเดอร์อื่น; อ้างผ่าน `/legacy-assets/<path>`
3. ก่อนใช้ภาพ hero ให้ตรวจ light/dark variant และขนาด responsive
4. การเก็บไฟล์นี้ไม่เท่ากับการนำไปใช้ในหน้า production; แต่ละการใช้ต้องผ่าน review ของโมดูลนั้น
